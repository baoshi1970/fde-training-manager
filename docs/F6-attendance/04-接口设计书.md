# 04 接口设计书（URL・请求）

基路径：`/attendance`（需登录，沿用现有 Spring Security 设置）。服务端渲染（Thymeleaf），非 JSON API。

## 1. 一览

| No. | 方法 | URL | 说明 | 成功时 |
|---|---|---|---|---|
| A1 | GET | `/attendance` | 课次一览 | 200，`attendance/list` |
| A2 | GET | `/attendance/{sessionId}` | 出勤登记画面 | 200，`attendance/form` |
| A3 | POST | `/attendance/{sessionId}` | 保存出勤 | 302 → `/attendance/{sessionId}` |

## 2. A1 GET /attendance

- 请求参数：无
- Model：

| 名称 | 类型 | 内容 |
|---|---|---|
| overviews | `List<AttendanceService.SessionOverview>` | 课次＋报名人数＋已记录人数 |

## 3. A2 GET /attendance/{sessionId}

- 路径参数：`sessionId`（Long）
- Model：

| 名称 | 类型 | 内容 |
|---|---|---|
| courseSession | `CourseSession` | 课次 |
| enrollments | `List<Enrollment>` | 该课次所属课程的报名者 |
| statuses | `Map<Long, AttendanceStatus>` | 学员id → 已保存状态（无记录者不在 Map 中） |
| counts | `Map<AttendanceStatus, Long>` | 各状态人数（无人为 0） |
| options | `AttendanceStatus[]` | 下拉框选项 |

- 异常：课次不存在 → `NotFoundException` → 404

## 4. A3 POST /attendance/{sessionId}

### 请求（`application/x-www-form-urlencoded`）

| 字段名 | 值 | 说明 |
|---|---|---|
| `status_{学员id}` | `PRESENT` / `LATE` / `ABSENT` / 空 | 空 ＝ 未记录；每个报名者 1 个字段 |
| （其他字段） | | 不以 `status_` 开头的字段一律忽略（含 CSRF 令牌等） |

### 处理结果

| 场景 | Flash | 重定向 |
|---|---|---|
| 成功 | `message`：「已保存出勤」 | `/attendance/{sessionId}` |
| 含非报名者的学员id | `error`：「学员（id=…）没有报名「…」，不能登记出勤。请先在报名管理里报名」，一条都不保存 | 同上 |
| 状态值非法（如 `XXX`） | `error`：「提交的出勤数据不正确，请刷新页面后重试」 | 同上 |
| 学员id 不是数字（如 `status_abc`） | 同上 | 同上 |
| 课次不存在 | — | 404 |

### 数据变更规则

| 提交值 | 库中已有记录 | 结果 |
|---|---|---|
| 某状态 | 无 | INSERT |
| 某状态 | 有 | UPDATE status |
| 空（未记录） | 无 | 不动 |
| 空（未记录） | 有 | DELETE |
| 请求里没有该学员的字段 | 有／无 | 不动 |
