# 06 单体测试规格书

- 方式：JUnit 5 ＋ Mockito（Service 层，不启动 Spring）
- 实施：`AttendanceServiceTest`、`SessionServiceTest`
- 运行：`mvnw.cmd test`（只跑本类：`mvnw.cmd test -Dtest=AttendanceServiceTest`）
- 「实际结果」栏在执行测试后填写。

## 3. 边界情况覆盖检查（CLAUDE.md：空、0、重复、相等）

| 观点 | 覆盖用例 |
|---|---|
| 空 | UT-ATT-03、04、06 |
| 0 | UT-ATT-06、08 |
| 重复（同一课次・同一学员） | UT-ATT-02（已有则更新） |
| 相等（状态不变再保存） | **未覆盖**：「已有记录且状态相同」时的行为（目前走更新分支，结果无害）。如需，可追加用例 |
