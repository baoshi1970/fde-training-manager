# 03 表定义书

## 1. 表：attendances（出勤）

- 实体：`domain.Attendance`
- 说明：课次 × 学员 → 出勤状态。同一课次・同一学员只有 1 条。「未记录」＝没有该行。

| No. | 物理名 | 逻辑名 | 类型 | 长度 | NULL | 键 | 说明 |
|---|---|---|---|---|---|---|---|
| 1 | id | 出勤ID | BIGINT | | NOT NULL | PK | 自动编号（IDENTITY） |
| 2 | session_id | 课次ID | BIGINT | | NOT NULL | FK → course_sessions.id | |
| 3 | trainee_id | 学员ID | BIGINT | | NOT NULL | FK → trainees.id | |
| 4 | status | 出勤状态 | VARCHAR | 20 | NOT NULL | | 字符串保存枚举名，见下表 |

> 外键引用的表名以 `CourseSession`、`Trainee` 实体上的 `@Table` 为准（本文档只记录 F6 新增的表）。

### 约束

| 名称 | 类型 | 对象 |
|---|---|---|
| PK | 主键 | id |
| UK | 唯一 | (session_id, trainee_id) |
| FK1 | 外键 | session_id → 课次表 |
| FK2 | 外键 | trainee_id → 学员表 |

### 枚举 AttendanceStatus（status 的取值）

| 值 | 显示名 |
|---|---|
| PRESENT | 出席 |
| LATE | 迟到 |
| ABSENT | 缺席 |

## 2. 关系图

```
courses 1 ──< course_sessions 1 ──< attendances >── 1 trainees
   │                                                    │
   └────────────< enrollments >─────────────────────────┘
```

- 谁有资格出现在某课次的出勤里，由 `enrollments`（学员 × 课程）决定；`attendances` 本身不存报名关系，保存时在 Service 里校验。

## 3. 删除时的依赖顺序

| 场景 | 处理 |
|---|---|
| 删除课次 | `SessionService.delete` 先 `deleteBySessionId`，再删课次 |
| 删除学员 | `TraineeService.delete`：有报名记录则拒绝（既有规则）；否则先 `deleteByTraineeId`，再删学员 |
| 重置为初始数据（`DataInitializer.resetToSeed`） | `attendances` **最先**删（依赖课次・学员），再依次删 enrollments → sessions → courses … |
